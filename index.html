Why can it be wrong?

Different values can illuminate the same bit positions. A positive result means every required bit is already set; it does not prove which value set them.

Negative results remain exact: one missing bit is enough to prove the value was never inserted.

The tallest registers come from the rarest hashes.

Why do leading zeros tell us the crowd size?

A long run of leading zeros is rare. Seeing one suggests that many independent hashes were sampled before that rare pattern appeared.

HyperLogLog spreads observations across registers, then combines their harmonic mean to reduce the influence of extreme values.

Exact vs estimate

estimate(x) = minr counter[r, hr(x)]

Collisions add noise, so estimates can be high — never low.

Why take the minimum?

Every row receives the true count plus collision noise. Taking the minimum chooses the least contaminated row while preserving the guarantee that the estimate does not fall below the truth.

More width reduces collisions; more depth reduces the chance that every row is badly contaminated.

04 / Under the hood

Uncertainty is a feature.

Exact structures grow with every distinct thing they remember. Probabilistic structures stay small by preserving only the evidence needed to answer one narrow question.
