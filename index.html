How to use Probably

Choose a laboratory, move a control, and compare the exact mathematical result with the simulated one.

  • Theory is computed analytically.
  • Simulation uses a deterministic seed, so the same URL recreates the same run.
  • The share link stores every parameter in the URL—no account or server required.
